# Illegal Gold Mining in the Amazon Rainforest

A static, 14-slide HTML presentation for a ninth-grade environmental science project.

## Present locally

Open `index.html` in a browser. For the most reliable full-screen experience, serve the folder with a simple local web server and open its local address.

Navigation:

- Right arrow, down arrow, Page Down, or space: next slide
- Left arrow, up arrow, or Page Up: previous slide
- Home / End: first / last slide
- F or the expand control: full screen
- Swipe left or right on a touch screen

## Publish with GitHub Pages

1. Sign in to GitHub and create a new empty repository.
2. Upload every file and folder from this project, preserving the `assets/images` folder.
3. Open the repository's **Settings**.
4. Choose **Pages** in the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then save.
7. Wait for GitHub to show the published site address.

Do not publish until the presentation has been reviewed and approved.

## Content rule

All presentation claims are condensed from the supplied PDF. The photographs are visual context only and do not add claims to the presentation.
